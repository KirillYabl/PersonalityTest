# Версия 1 планы

## Кратко

Тест в telegram mini app, где юзер отвечает на вопросы и получает результат

## Подробно

### API

1. Ручка списка вопросов: присылает список вопросов
2. Ручка приема ответов (по одному): принимает ответ
3. Ручка текущих ответов юзера: присылает список вопросов и ответ юзера для отрисовки
4. Ручка получения результата: Проверяет, что юзер на все ответил, если нет, то присылает оставшиеся вопросы, если да, то присылает результат
5. Ручка начала прохождения теста: создает новую сессию прохождения теста

### UI

1. Telegram miani apps
2. Показывает все вопросы длинной простыней с ответами (при открытии)
3. Показывает прогресс (считает на своей стороне, т.к. знает все вопросы и ткущее состояние)
4. В конце кнопка получить результат
5. При отображении результата кнопка пройти заново
